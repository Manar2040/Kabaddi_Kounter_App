# 🏆 **Kabaddi Kounter App**  

A **modern** and **intuitive** Kabaddi score-tracking app built with **Kotlin** and **Jetpack components**. 📱✨  

---

## 🔥 **Features**  
👉 **Real-time score tracking** for two teams  
👉 **Increment scores** by ➕1⃣ or ➕2⃣ points  
👉 **Automatic WIN detection** at **15 points** 🏅  
👉 **Score history tracking** 📝  
👉 **Reset functionality** 🔄  
👉 **Clean and intuitive UI** 🎨  

---

## 🛠 **Technical Details**  
🚀 **Built with:** **Kotlin**  
🏢 **Architecture:** **MVVM (Model-View-ViewModel)**  
👉 **Data Binding** for seamless UI updates  
💪 **LiveData** for reactive updates  
📝 **RecyclerView** to display score history  
🔄 **ConstraintLayout** for responsive UI
